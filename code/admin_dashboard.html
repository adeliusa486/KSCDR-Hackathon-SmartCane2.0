Create the admin password

This password protects the cane's Wi-Fi and Bluetooth settings. The camera view stays public. At least 8 characters.

For safety the first password can only be created on the cane's own network. On the same Wi-Fi as the cane, open http://smartcane.local:8080/admin (or the cane's address with :8080/admin), create it there, then come back here.
