# Phase prompts

One file per phase, written when the previous phase passes its gate:
`phase2.md` after the Phase 1 gate, and so on. Each one is the master plan
(`../consumer-readiness-plan.md`) section for that phase, rewritten with what
the finished phases measured.

Adeel asked for all remaining phases early, so Phases 2 to 5 exist as drafts.
A draft is finalised (renamed without `_DRAFT`) only at the gate before it,
with every *(gate)* and *(Phase N)* placeholder filled from measured results.
